Política de Privacidade

Aplicativo lawyer — atualizada em 6 de outubro de 2026

Quais dados o app guarda

O lawyer é uma ferramenta para escritórios de advocacia cadastrarem clientes, partes contrárias, testemunhas e outros contatos. Os dados digitados pelo usuário (como nome, CPF, RG, data de nascimento, telefones, e-mail, endereço, profissão, estado civil e anotações) são armazenados somente no próprio aparelho do usuário (ou no navegador, na versão web).

Envio de dados

O app não possui servidor próprio, não exige cadastro ou login e não envia os dados dos cadastros para o desenvolvedor nem para terceiros. Não há publicidade, rastreamento ou coleta de estatísticas de uso.

A única comunicação externa acontece quando o usuário digita um CEP: apenas o número do CEP é enviado ao serviço público ViaCEP (viacep.com.br) para preencher o endereço automaticamente.

O app pode baixar atualizações do próprio aplicativo pelo serviço Expo (expo.dev). Esse processo não envia dados dos cadastros.

Responsabilidade pelos dados

O escritório que utiliza o app é o controlador dos dados pessoais cadastrados e responsável por tratá-los de acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018). Recomenda-se proteger o aparelho com senha ou biometria.

Exclusão dos dados

Qualquer cadastro pode ser excluído dentro do app. Desinstalar o app (ou limpar os dados do navegador, na versão web) apaga todos os cadastros de forma definitiva.
